# Spotify Data Analysis Dashboard – Power BI Project

This project is an interactive Spotify Data Analysis Dashboard created using Power BI to analyze music streaming trends, track popularity, artist performance, and user engagement through data visualization and KPI analysis.

The dashboard was designed to transform raw Spotify dataset information into meaningful insights using interactive charts, filters, slicers, and DAX measures. The main objective of this project was to understand listening patterns and present the data in a visually appealing and easy-to-understand format.

## Key Features

• Interactive dashboard with dynamic filtering and navigation
• KPI cards to track important metrics and performance indicators
• Analysis of track popularity and artist performance
• Visual representation of music trends and engagement patterns
• User-friendly design with clean dashboard layout and visuals
• Use of DAX measures for calculations and data insights

## Tools & Technologies Used

• Power BI
• DAX Measures
• Data Visualization
• KPI Reporting

## Project Insights

The dashboard helps identify top-performing artists, trending tracks, and engagement behavior through visual analytics. It also demonstrates how business intelligence tools can be used to convert data into actionable insights and support data-driven decision-making.
